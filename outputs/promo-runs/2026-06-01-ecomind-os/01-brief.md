## 一、产品定位与目标观众

### 产品定位

EcoMind OS 是中国首个面向生态环境垂直领域的 AI Agent 管理平台，由一套零外部框架依赖的自建 Agent 引擎（EcoAgentEngine）驱动，覆盖执法、监测、审批、公众四大角色场景，并内置六层安全链与国密合规体系，专为政务级别的生产环境而生。

它不是又一个"AI 赋能生态"的概念 Demo——EcoMind OS 经过 120 轮端到端压力测试，具备 83% 生产就绪度，承载真实的省级地形 3D 数字孪生，连接现实中的湖南省环境监测站实时数据流。其核心理念"会思考的生态大脑（A Thinking Ecological Brain）"是对这套体系最精准的自我定义：AI 不只是工具，而是能够在合规框架内主动推理、自主决策的生态治理伙伴。

与通用 AI 平台相比，EcoMind OS 的差异化在于：**专域**（只解决生态环境的问题）、**自主**（不依赖 LangChain/CrewAI，可国产化替换）、**合规**（SM2/SM3/SM4 国密 + 等保合规 UI，通过 20/20 对话真实性测试）。

### 目标观众

| 层次 | 受众身份 | 观看场景 | 核心关注点 |
|------|---------|---------|-----------|
| 决策层 | 省/市级生态环境局信息化主任、CIO | 技术会议演示、官网 | 合规性、国产化、稳定性 |
| 技术评估层 | 政务系统技术负责人、生态环境技服商研发 | GitHub 主页、官网 | 架构可审计、零外部依赖、测试数据 |
| 业务使用层 | 企业环保合规部门（碳排/排污许可） | 官网介绍页 | 场景贴合度、操作易用性 |

## 三、推荐视觉风格

### 推荐：**A. 科技纪录片风**（深色背景 + 数据流 + 真实界面截图）

**推荐理由**：

EcoMind OS 的目标观众是政务决策层和技术评估层，他们对"酷炫但空洞"高度警惕，对"可信且专业"高度敏感。科技纪录片风能够在保持视觉张力的同时，以**真实数据和真实 UI 截图**作为信任背书——这与 EcoMind OS"不是 Demo，是生产系统"的核心差异化高度契合。

品牌色生态绿 `#00C9A7` → 智慧青 `#0E7490` 在深色底上发光感极强，既呼应生态主题（自然绿意），又传递科技智慧感（青蓝冷峻）。叶脉轮廓 × AI 神经网络拓扑的 Logo 概念，在深色环境中用渐变发光线条表现，可以成为全片最有辨识度的视觉语言。

| 参数 | 规格 |
|------|------|
| **底色** | 深宇宙黑 `#050A0E` + 微弱数据流网格 |
| **主文字** | 超大白字 + 品牌绿高亮关键词，字重 200-300，Inter/思源黑体 |
| **产品界面** | 真实 UI 截图 + 发光边框，适当模糊背景突出焦点 |
| **数据动效** | 数字滚动、折线爬升、热力图扩散、代码流 |
| **品牌绿运用** | 关键指标高亮、连接线、边框发光、Logo 动效 |
| **忌讳** | 禁止使用空洞粒子爆炸特效、禁止用大量自然风景填充时长、禁止 AI 机器人拟人形象 |
