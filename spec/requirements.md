# EcoMind OS Chat — 需求规格书

> 版本：v6.5 | 最后更新：2026-05-27
> 范围：Chat 智能对话模块（前端）

---

## 一、模块愿景

GAIA 生态主控 —— 面向湖南省生态环境厅的 AI 对话中枢。集成 DeepSeek 大模型、7 位领域专家、真实环境数据、嵌入式地图。

## 二、核心需求

### P0 — 已实现
- 流式 SSE 对话（flushSync 逐字渲染）
- 7 位专家切换（GAIA/监测/执法/环评/碳/应急/水）
- 对话记忆（最近 20 条上下文）
- API Key 浏览器热配置（localStorage + .env 注入）
- 真实 DeepSeek API 代理

### P1 — 部分实现
- 城市检测 + 环境数据卡片（AQI/水质/监测站）
- ChatMapEmbed 嵌入式地图
- 停止流式输出
- 请求监控日志

### P2 — 待实现
- 对话导出/分享
- 消息搜索
- 语音输入/输出
- 技能面板集成
- 连接器集成
