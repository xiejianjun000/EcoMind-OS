# 变更提案：消息全文搜索

### 是什么
为 Chat 页面添加消息全文搜索功能。用户输入关键词，实时过滤和高亮匹配的消息。

### 为什么
1. 长对话中快速定位某条消息
2. 环境执法人员需要回溯特定咨询内容
3. Header 中 Search 图标按钮已有占位但无功能

### 范围
- 搜索输入框（Header 展开/收起）
- 实时过滤消息列表
- 匹配关键词高亮
- 匹配计数 + 上下导航
- Escape 关闭搜索

### 影响
- Chat/index.tsx：新增搜索状态 + 过滤逻辑 (+50行)
- MessageBubble：高亮渲染 (+20行)
- 无需新增文件（内联实现）

### 风险
| 风险 | 等级 | 缓解 |
|:---|:---|:---|
| 大量消息搜索性能 | 低 | 前端过滤，消息量有限（<100条） |
