# 导出与分享 — 场景规格

### 场景 1：导出 Markdown
- **Given** 对话中有多条消息（含环境数据卡片）
- **When** 用户点击「导出 Markdown」
- **Then** 浏览器下载 .md 文件
- **And** 环境数据以表格形式呈现
- **And** 文件名格式：`EcoMind-对话-2026-05-27-1830.md`

### 场景 2：复制全文
- **Given** 对话中有消息
- **When** 用户点击「复制全文」
- **Then** 剪贴板包含完整对话文本
- **And** 显示「已复制」Toast 提示

### 场景 3：分享链接
- **Given** 对话中有消息
- **When** 用户点击「生成分享链接」
- **Then** 弹出 ShareDialog
- **And** 显示可复制链接 + 二维码
- **And** 链接包含压缩后的对话 JSON（URL hash）

### 场景 4：空对话
- **Given** 对话为空（无消息）
- **When** 用户点击导出/分享按钮
- **Then** 按钮 disabled，提示「暂无对话内容」
