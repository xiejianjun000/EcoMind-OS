# Chat UI — 场景规格

### 场景 1：流式对话
- **Given** 用户已配置 API Key
- **When** 用户输入消息并发送
- **Then** 回复逐字流式渲染，光标闪烁至流式结束
- **And** 流式结束后显示操作按钮（点赞/复制/朗读）

### 场景 2：专家切换
- **Given** 用户在 Chat 页面
- **When** 用户从下拉菜单选择「执法监察专家」
- **Then** 系统提示词切换为执法监察角色
- **And** 后续回复体现执法专业视角

### 场景 3：环境数据卡片
- **Given** 用户消息包含城市名（如「娄底」）
- **When** AI 回复完成
- **Then** 回复下方显示该城市 AQI 数据卡片
- **And** 卡片下方嵌入 OpenStreetMap 地图

### 场景 4：错误处理
- **Given** API Key 无效或网络断开
- **When** 用户发送消息
- **Then** 显示明确错误提示（非白屏/死循环）
- **And** 用户可重新发送

### 场景 5：停止生成
- **Given** AI 正在流式输出
- **When** 用户点击「停止」按钮
- **Then** 流式立即中断，已输出内容保留
