# 变更提案：对话导出与分享

### 是什么

为 Chat 页面添加对话导出和分享功能。用户可将当前会话导出为 Markdown/PDF/文本格式，或生成分享链接供他人查看。

### 为什么

1. **业务刚需**：环境执法人员需要将 AI 咨询记录导出为办案参考材料
2. **协作场景**：处长/厅领导需要分享 AI 分析结果给同事
3. **合规审计**：对话记录作为决策依据需要留档
4. **当前状态**：Header 中有 Share2 图标按钮但无实际功能

### 范围

| 功能 | 交付物 | 说明 |
|:---|:---|:---|
| 导出 Markdown | ExportMenu 组件 | 格式化对话 + 环境数据卡片为 .md 文件 |
| 导出 PDF | 复用 Markdown → 浏览器打印 | 无需额外依赖 |
| 复制全文 | Clipboard API | 一键复制到剪贴板 |
| 分享面板 | ShareDialog 组件 | 生成链接 / 二维码 |

### 影响

- **Chat/index.tsx**：新增导出/分享逻辑，约 +60 行
- **新增文件**：ExportMenu.tsx、ShareDialog.tsx，约 200 行
- **无后端依赖**：纯前端实现

### 风险

| 风险 | 等级 | 缓解 |
|:---|:---|:---|
| 长对话导出性能 | 低 | 仅导出当前可见消息（最多 50 条） |
| 环境数据卡片渲染 | 低 | Markdown 表格替代 HTML |
