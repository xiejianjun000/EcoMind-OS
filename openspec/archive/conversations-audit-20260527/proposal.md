# Proposal: 对话审计页面

> 状态：进行中 | 日期：2026-05-27

## 是什么

将 Conversations 页面从 19 行占位符升级为完整的对话审计管理界面。

## 为什么

1. 当前 `/admin/audit` 路由指向的 Conversations 页面仅有 `Title + Paragraph`，无实际功能
2. chatStore 已有完整的 session 数据（Zustand persist），可直接复用
3. 对话审计是政务系统的合规要求 —— 所有 AI 对话需可追溯、可审查
4. 与 Chat v6.5 模块形成闭环：用户在 Chat 页面的所有对话，需在审计页统一管理

## 范围

- 会话列表：展示所有历史会话（标题、时间、消息数、专家）
- 搜索与过滤：按标题/专家/时间范围筛选
- 删除操作：支持单条/批量删除（带确认）
- 详情预览：点击会话查看消息摘要
- 数据来源：chatStore sessions + messages

## 不做

- 不涉及后端 API 改动
- 不涉及会话内容全文搜索（已在 task-009 实现）
- 不涉及导出功能（已在 task-008 实现，可复用）
