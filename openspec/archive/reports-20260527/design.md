# 报告生成模块 — 设计文档

## 三种报告模板
1. 监测报告：日期/区域/AQI/结论
2. 执法报告：案件编号/企业/违法行为/处罚决定
3. 审批报告：审批编号/类型/结果/意见

## API
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/reports | 列表 |
| POST | /api/reports | 生成报告（report_type + params） |
| GET | /api/reports/{id} | 详情 |
