## 一、Business Model Canvas（9模块）

### 1. 客户细分 (Customer Segments)

| 细分市场 | 描述 | 优先级 | 付费能力 |
|---------|------|:------:|:--------:|
| **市级生态环境局** | 信息化预算充足，有数字化转型需求 | P0 | 高（50-500万/项目） |
| 区县级生态环境局 | 预算有限，跟随市级采购 | P1 | 中（10-50万/项目） |
| 环境监测第三方运维公司 | 设备运维商，需要智能化工具提升效率 | P2 | 中（按站点订阅） |
| 环评编制单位 | 需要数据支持和报告辅助 | P3 | 低（个人付费意愿低） |

### 2. 价值主张 (Value Propositions)

| 对客户细分 | 核心价值 | 差异化 |
|-----------|---------|--------|
| 市级生态环境局 | 打通数据孤岛、AI辅助决策、提升监管效能 | 垂直领域深度 > 通用平台广度 |
| 区县级生态环境局 | 低成本获得市级同等的智能化能力 | SaaS模式降低准入门槛 |
| 第三方运维公司 | 降低人工巡检成本、提升响应速度 | AI预警替代人工盯盘 |

### 3. 渠道通路 (Channels)

| 渠道 | 描述 | 阶段 |
|------|------|------|
| **政府招标采购** | 通过政府采购网公开招标或竞争性磋商 | MVP验证后 |
| 行业展会/论坛 | 中国环博会、生态环境技术大会等 | 持续 |
| 标杆案例 | 通过1-2个标杆城市的成功案例辐射 | MVP验证后 |
| 主管部门推荐 | 通过省级生态环境厅的推荐和试点 | 中期 |
| 合作伙伴 | 与环保设备厂商、系统集成商合作 | 中期 |

### 4. 客户关系 (Customer Relationships)

| 模式 | 描述 |
|------|------|
| 专属项目经理 | 大客户配备专属项目经理 |

| 技术培训 | 提供系统使用培训和AI操作指南 |
| 7x24支持 | 生产环境提供技术支持热线 |

## 二、关键商业指标估算

### 场景C（混合模式）估算

| 指标 | 估算值 | 依据 |
|------|--------|------|
| **CAC（获客成本）** | 5-15万/客户 | 政府客户需多次拜访、演示、试点；含差旅和人力 |
| **LTV（客户终身价值）** | 50-200万/客户 | 首年项目费100-300万 + 5年运维费50-150万 |
| **回本周期** | 6-12个月 | 首年项目收入即可覆盖获客成本 |
| **毛利率** | 60-75% | 软件项目人力成本为主，LLM/API成本占比较小 |

### 敏感性分析

| 变量 | 乐观 | 基准 | 悲观 |
|------|------|------|------|
| 年新增客户数 | 5个 | 2-3个 | 0-1个 |
| 平均项目金额 | 300万 | 150万 | 50万 |
| 年经常性收入 | 90万 | 30万 | 5万 |
| 盈亏平衡点 | 第14个月 | 第24个月 | 无法盈利 |

## 三、最小可行商业模式（MVP阶段）

手册Ch5原文：*"增长可重复：用户获取来自明确渠道，CAC、LTV、回本周期等指标可解释、可防守。"*

MVP阶段不需要完整的商业模式，但需要验证以下**最小假设**：

| 假设 | 验证方式 | 通过标准 |
|------|---------|---------|
| 有人愿意用 | 5个试点用户连续使用2周 | WAU ≥60% |
| 有人认为有价值 | 用户反馈 + NPS | NPS ≥30 |
| 有人愿意推广 | 用户主动推荐给同事 | ≥1次自发推荐 |
| 有人愿意付费 | 试点单位对付费模式的反馈 | ≥1个单位表示"如果...我们愿意付" |
| 获客路径可行 | 从接触到签约的转化过程可复现 | 至少1条可复制的获客路径 |

**MVP阶段不要求**：盈利、规模化增长、多元收入来源。这些是发布和规模化阶段的目标。

## 四、推荐的商业路径

### Phase 1：免费试点（Month 1-3）

- 目标：获取使用数据和成功案例
- 策略：找到1-2个关系良好的监测站，免费部署，换取使用反馈和案例授权
- 产出：案例研究、使用数据、产品改进方向

### Phase 2：标杆项目（Month 4-6）

- 目标：获取第一个付费客户
- 策略：用试点案例参与政府采购或直接对接市级生态环境局
- 产出：第一个商业合同、收入验证、客户案例

### Phase 3：区域复制（Month 7-12）

- 目标：在同一省/区域内复制2-3个项目
- 策略：通过标杆案例辐射，与系统集成商合作扩大覆盖
- 产出：区域品牌、稳定收入流、规模验证

### Phase 4：产品化+SaaS（Year 2）

- 目标：从项目制向产品化转型
- 策略：提炼通用产品、开发SaaS版本、降低获客成本
- 产出：标准化产品、SaaS收入、规模化增长
