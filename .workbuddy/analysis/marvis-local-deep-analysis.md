## 三、核心能力深度解析

### 3.1 硬件抽象层 — 操作系统级 API 贯通

Marvis 最核心的差异化能力是**不依赖 UI 模拟点击或 RPA 脚本**，而是直接穿透到操作系统底层 API：

```
传统桌面 Agent（如 OpenClaw/Cowork）:
  UI 层 → 模拟点击/键盘 → 应用操作
  缺点: UI 变化即失效，脚本脆弱

Marvis 操作系统层级:
  自然语言 → PM Agent → 子 Agent → Windows 原生 API 调用
  优点: 不依赖 UI 布局，抗界面变更
```

**已验证的系统级能力**：

| 能力域 | 具体操作 | 技术路径 |
|:---|:---|:---|
| **硬件检测** | CPU型号/频率、内存容量/占用、GPU型号/显存、电池健康度、网络速度 | 直接调用 Windows System Information API / WMI |
| **系统设置** | 屏幕分辨率、夜间模式、电源计划、锁屏广告（Windows 聚焦）关闭 | Windows Settings API / 注册表操作 |
| **进程管理** | 启动项管理、后台进程扫描与终止、资源占用优化 | Windows Service/Process API |
| **文件系统** | 跨目录批量操作、文件流读写 | Windows File I/O API |
| **网络控制** | 网络状态查询、速度测试 | Windows Networking API |

**GAIA-ECO 适配价值**：
- 生态环境监测设备（CEMS/VOCs/水质）可通过相同 API 抽象层接入
- 无需为每种监测设备开发专用驱动，统一通过 Marvis 中间层调度

### 3.2 屏幕感知机制 — GUI Agent + OCR 多模态

Marvis 的屏幕感知与传统的"截图→OCR→理解"管道不同，采用**多层次感知**：

```
层次 1: OCR 文字识别（File Agent 内置）
  · 图片中文字提取
  · 截图文字搜索："找一张关于XX的截图"
  · 隐私模式下 100% 本地 OCR（本地小模型）

层次 2: 图片内容理解（File Agent 内置）
  · 场景识别（游戏截图/工作文档/设计稿）
  · 人像识别与分类
  · 多维度标签：场景 + 人物 + 文字 + 时间

层次 3: GUI Agent 自动化（App Agent + Browser Agent）
  · 理解应用界面结构（非像素级截图，而是 DOM/控件树）
  · 一句话驱动应用："微信给小张发消息"
  · 跨应用工作流：浏览器查数据 → Excel 制表

层次 4: 系统状态感知（Computer Agent）
  · 硬件传感器数据读取
  · 系统事件监听（应用安装/卸载/崩溃）
  · 网络状态实时监控
```

**OCR 引擎推测**：
- 高效模式：云端 OCR（混元/DeepSeek 多模态能力）
- 隐私模式：本地轻量 OCR 模型（参数规模未公开）
- 索引阶段：边缘侧基础过滤模型，避免对敏感文件进行 OCR 扫描

**GAIA-ECO 适配价值**：
- 执法取证场景：可直接复用 OCR + 图片场景识别能力
- 排放监测：可通过 GUI Agent 自动操作 CEMS 监测软件界面
- 许可证核验：扫描许可证图片 → OCR 提取关键字段 → 自动比对合规数据库

### 3.3 安全机制 — L2 硬确认 + 端云隔离

Marvis 实现了业界领先的多层安全体系：

#### 3.3.1 L2 硬确认机制

```
普通 AI Agent（L1 软确认）:
  用户说"删掉没用的文件" → AI 判断 → 直接执行
  风险: AI 误判导致数据丢失

Marvis（L2 硬确认）:
  用户说"删掉没用的文件" → AI 筛选待删文件 → 呈现执行计划 → [等待用户确认] → 执行
  覆盖范围:
  ✅ 系统配置修改（分辨率/电源/注册表）
  ✅ 文件删除/批量删除
  ✅ 权限变更（应用权限/文件权限）
  ✅ 交易操作（架构性禁用支付功能）
```

#### 3.3.2 三层安全域

```
┌─────────────────────────────────────────┐
│           Layer 1: 操作确认层             │
│  · L2 硬确认（敏感操作强制用户审批）        │
│  · 执行前计划呈现（全透明，可逐项审查）      │
│  · 高危操作拦截（交易类架构性禁用）         │
└─────────────────────────────────────────┘
          │
┌─────────────────▼───────────────────────┐
│           Layer 2: 数据隔离层             │
│  · 隐私模式: 零云上传，所有数据本地处理     │
│  · 文件索引: 用户指定扫描范围 + 一键排除    │
│  · 边缘过滤: 基础模型预过滤敏感文件        │
│  · 沙箱环境: 继承 QClaw 隔离方案          │
└─────────────────────────────────────────┘
          │
┌─────────────────▼───────────────────────┐
│           Layer 3: 身份认证层             │
│  · 微信/QQ 账号统一登录                   │
│  · 设备绑定（跨端同步基础）               │
│  · 操作审计日志（全链路追踪）              │
└─────────────────────────────────────────┘
```

#### 3.3.3 隐私保护核心技术

| 机制 | 说明 |
|:---|:---|
| **文件扫描范围控制** | 首次启动时用户定义扫描文件夹范围，可永久排除敏感目录 |
| **本地过滤模型** | 边缘侧基础模型预过滤，避免对个人/涉密文件进行索引 |
| **端侧全处理** | 隐私模式下，OCR + 图片识别 + 对话全部本地运行，零云端泄漏 |
| **模型预热** | 自动模式预测用户需求，提前加载本地模型，减少模式切换延迟 |
| **数据最小化** | 高效模式下仅上传必要数据完成复杂任务，非全量同步 |

**GAIA-ECO 适配价值**：
- 政务合规：隐私模式满足等保要求，环境执法数据不出设备
- 证据链完整性：全链路审计日志满足执法合规
- 沙箱隔离：参考 QClaw 方案，为生态环境 Agent 创建独立执行环境

## 五、跨端协同架构

### 5.1 双向控制体系

```
         PC（Windows/Mac）         ←──────────→        Android 手机
         ┌──────────────┐                             ┌──────────────┐
         │ Marvis 桌面端 │                             │ Marvis 移动端 │
         │              │      同一微信/QQ 账号绑定       │              │
         │ · 本地执行    │◄──────────────────────────►│ · 远程监控    │
         │ · 系统API调用  │                             │ · 指令下达    │
         │ · 文件管理    │     实时屏幕镜像 + 触控交互    │ · 状态同步    │
         │ · 应用控制    │                             │ · 离线接管    │
         └──────────────┘                             └──────────────┘
```

| 能力 | 说明 |
|:---|:---|
| **手机看 PC 屏幕** | 实时屏幕镜像，完整触控交互，即使 PC 锁屏也能操作 |
| **手机遥控 PC** | 远程打开文件、执行任务、查看状态 |
| **PC 控制手机应用** | 通过应用宝引擎，PC 可操作手机上安装的 Android 应用（如同花顺、非常准） |
| **离线接管** | PC 断网 → 手机自动切换为云端独立 Marvis 实例继续处理 |
| **场景** | 老人远程协助：在手机上接管父母 PC，如同坐在电脑前 |

- 14 年跨平台技术积累，4 年跨端专项研发
- Windows ↔ Android 双向应用调用
- 竞品（Microsoft Copilot/Siri）无法快速复制的壁垒
