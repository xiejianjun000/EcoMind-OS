## 第一章 项目概述与总体架构

### 1.1 项目目标

开发一套部署于U盘的多智能体协作审计系统，对固定污染源烟气连续监测系统（CEMS）、水污染源在线监测系统（WQMS）和挥发性有机物连续监测系统（VOCs）工控机进行全链路、自动化、合规性审计，重点查处嵌入作弊软件、参数篡改、物理干扰、虚假标记等弄虚作假行为。

五大核心能力：即插即审、深度见底、智能研判、自进化学习、远程掌控。

## 第二章 近200条规则详细定义

### 2.1 技术合规与反造假专项规则 (R001-R050)

**R001 分析仪/工控机隐藏菜单与后门扫描**
- 检测逻辑：使用YARA规则库扫描工控机及分析仪固件，匹配已知的隐藏菜单入口、后门程序、默认工程密码等特征
- 适用模式：快速/标准/完整
- 法律映射：《办法》第4条第9项；环办监测函〔2024〕214号

**R002 进程白名单与可疑进程扫描**
- 检测逻辑：提取工控机所有运行进程，与验收基线进程白名单比对，标记新增/缺失进程
- 适用模式：快速/标准/完整
- 法律映射：《办法》第4条第8项；《刑法》第286条

**R003 电子记录/日志完整性深度扫描**
- 检测逻辑：扫描系统日志、操作日志、参数修改日志，检测长时段空白、异常删除、时间戳倒退或回填等痕迹
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项/第11项；《大气污染防治法》第24条

**R004 全参数一致性快检**
- 检测逻辑：分析仪EEPROM参数、数采仪配置参数、工控机软件参数与验收报告、备案文件四方比对
- 适用模式：快速/标准/完整
- 法律映射：《办法》第4条第8项；《大气污染防治法》第24条

**R005 数据保持/恒值输出功能审计**
- 检测逻辑：检查"维护""校准"状态下是否存在数据锁定功能
- 适用模式：标准/完整
- 法律映射：环办执法函〔2021〕484号；HJ 212-2025

**R006 模拟信号注入/旁路功能检测**
- 检测逻辑：检测是否存在可导入外部数据替代真实监测数据的接口或功能
- 适用模式：标准/完整
- 法律映射：《办法》第5条第5项；《刑法》第286条

**R007 双套算法/参数集检测**
- 检测逻辑：同时读取"显示"和"原始记录"两个通道的数据，比对是否存在人为偏差
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项；《产品质量法》

**R008 远程控制/维护通道审计**
- 检测逻辑：扫描网络配置、开放端口、远程桌面服务、第三方远程软件
- 适用模式：标准/完整
- 法律映射：环办监测函〔2024〕214号；《刑法》第285条

**R009 基准模式序列/预设数据包检测**
- 检测逻辑：分析校准后数据序列，识别可预测的固定值排列
- 适用模式：标准/完整
- 法律映射：《办法》第5条第5项

**R010 设备认证与铭牌一致性校验**
- 检测逻辑：核验CCEP认证证书真伪，比对铭牌信息与认证证书、备案文件
- 适用模式：快速/标准/完整
- 法律映射：《产品质量法》第53条

**R011 非法修改程序固件检测**
- 检测逻辑：哈希校验比对当前固件与厂家官方原始固件
- 适用模式：标准/完整
- 法律映射：《刑法》第286条

**R012 "飞检"时空矛盾分析**
- 检测逻辑：核验同一采样人员/设备在同一天的采样任务地理分布和时间是否物理可行
- 适用模式：标准/完整
- 法律映射：《办法》第5条第6项

**R013 软件阈值/限值设定审计**
- 检测逻辑：检查是否存在非法的数据输出上限、下限或过滤规则
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项

**R014 颗粒物采样嘴/探杆物理合规性检查**
- 检测逻辑：核验采样嘴尺寸、朝向、探杆长度是否与备案一致
- 适用模式：标准/完整
- 法律映射：HJ 75-2017；GB/T 16157-1996

**R015 回流气/尾气稀释干扰评估**
- 检测逻辑：计算回流气出口与采样嘴间距，建立模型评估稀释干扰程度
- 适用模式：标准/完整
- 法律映射：《办法》第4条第4项；《大气污染防治法》第20条

*(R016-R050 预留：防爆、防腐蚀、电源冗余等硬件安全要求)*

### 2.2 数据逻辑与真实性校验规则 (R051-R100)

**R051 氨氮-总氮逻辑矛盾检测**
- 检测逻辑：逐条比对氨氮与总氮值，标记氨氮>总氮的记录
- 适用模式：快速/标准/完整
- 法律映射：《水污染防治法》第39条/83条

**R052 COD-BOD/高锰酸盐指数逻辑矛盾检测**
- 检测逻辑：标记COD<BOD等违反化学原理的记录
- 适用模式：标准/完整
- 法律映射：《水污染防治法》第39条

**R053 多因子同步骤降/骤升检测**
- 检测逻辑：监测多个因子是否发生无工况支持的同步剧烈变化
- 适用模式：标准/完整
- 法律映射：《办法》第4条第2项/第4项/第6项

**R054 长期恒值/低波动异常检测**
- 检测逻辑：计算变异系数(CV)，标记变化幅度长期低于量程1%的时段
- 适用模式：快速/标准/完整
- 法律映射：《办法》第4条第8项；HJ 75/356

**R055 治理设施-排放数据逻辑一致性校验**
- 检测逻辑：治理设施运行参数与排放浓度时间轴对齐和相关性分析
- 适用模式：标准/完整
- 法律映射：《办法》第4条第3项；《大气污染防治法》第20条

**R056 生产工况-排放数据逻辑一致性校验**
- 检测逻辑：生产负荷与排放数据时序关联分析
- 适用模式：标准/完整
- 法律映射：《办法》第4条第3项

**R057 烟气参数-排放数据物理一致性校验**
- 检测逻辑：基于烟气组分比例计算理论值与实测值偏差
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项

**R058 数据突变/阶跃信号检测**
- 检测逻辑：LightGBM或滑动窗口算法检测突然阶跃
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项；HJ 75

**R059 数据过度平滑/规律性波动检测**
- 检测逻辑：分析频谱特征和自相关性
- 适用模式：标准/完整
- 法律映射：《办法》第4条第8项

**R060 排放总量与物料衡算的逻辑矛盾检测**
- 检测逻辑：基于排污许可证反推理论排放浓度范围
- 适用模式：标准/完整
- 法律映射：《环境保护税法》；《排污许可管理条例》

**R061 校准/校验数据与运行数据的时间逻辑校验**
- 检测逻辑：核验校准时间戳是否在工作时间、是否在运维计划内
- 适用模式：标准/完整
- 法律映射：HJ 355/75

**R062 反吹/维护操作与数据响应的逻辑校验**
- 检测逻辑：分析反吹后数据响应时间、恢复时间是否符合物理预期
- 适用模式：标准/完整
- 法律映射：《办法》第5条第1项

**R063 多监测点位间数据逻辑一致性校验**
- 检测逻辑：比对同一企业多个排放口排放数据的相关性
- 适用模式：标准/完整

**R064 监测数据与气象/季节变化逻辑一致性校验**
- 检测逻辑：分析排放浓度与气温、湿度、季节性生产规律的相关性
- 适用模式：完整模式

**R065 排放量数据连续性/完整性校验**
- 检测逻辑：识别浓度数据正常但排放量数据长期为零或空值的断点
- 适用模式：快速/标准/完整
- 法律映射：HJ 212-2025

*(R066-R100 预留：更多数据逻辑与真实性校验规则)*

### 2.3 物理链路与环境完整性审计规则 (R101-R130)

**R106 FID/分析仪核心传感器状态诊断**

### 2.5 第三方检测/手工监测报告审计规则 (R161-R180)

## 第三章 技术实现与部署方案

### 3.1 五智能体协同工作流

1. **Guardian (门神)** 启动：独立systemd服务，只读挂载目标磁盘，SHA256校验"黄金基线"
2. **Sentry (哨兵)** 快速扫描：OpenClaw并行调度R001-R015等规则，5分钟内完成初步筛查
3. **Sherlock (神探)** 深度取证：调用协议适配器插件读取分析仪内部数据，执行R051-R110
4. **Expert (专家)** 智能研判：汇总结果，运行R111-R200，调用本地LLM进行法律映射和证据链组装
5. **Librarian (智库)** 实时支持：提供法规、案例、特征库的实时检索

### 3.2 关键技术实现

- 物理链路三端同步分析：插件式协议适配器，覆盖≥15个主流品牌
- 自进化学习引擎：Hermes Agent自动生成新检测Skill
- 置信度复合计算模型：模式基础分 × 协议覆盖系数 × 数据完整系数
- 报告分级输出：执行摘要(PDF)、技术报告(HTML)、法证报告(ZIP)

### 3.3 U盘部署方案

- 硬件：≥64GB工业级U盘，SLC/MLC颗粒，带物理写保护开关
- 系统：Ventoy引导管理器，Ubuntu 22.04 Live Server + WinPE双环境
- 存储分区：FAT32启动区 + ext4持久化存储区 + exFAT审计数据输出区 + LUKS加密证据区
- 自启动：systemd服务链依次启动Guardian、Hermes API和OpenClaw
