## 一、项目背景与定位

### 1.1 立项初衷

当前，人工智能技术正深刻变革各行各业的治理方式。生态环境领域具有法规体系复杂、数据来源多元、执法链条长、专业门槛高等显著特点，亟需一套"懂生态环境、懂法规标准、能调用工具、能辅助决策"的专用 AI 操作系统。

2026 年 5 月，研发组启动 EcoMind OS 项目，定位为**国内首个生态环境垂直领域 AI Agent 操作系统**。目标不是做一个"聊天机器人"，而是构建一套完整的多专家协同、工具执行、安全治理、持续进化的智能协作平台。

### 1.2 技术定位

EcoMind OS 对标全球顶级开源 Agent 系统（Hermes Agent / Claude Code / OpenClaw），在自主性、可扩展性、安全合规性三个维度上，为生态环境政务场景做了深度定制：

- **完全自建 Agent 引擎**：不依赖 LangChain、AutoGPT 等任何外部 Agent 框架，纯 Python asyncio + HTTPX 实现，共 17 个引擎模块，约 30,000 行后端代码。
- **国密安全体系内置**：SM2/SM3/SM4 国密算法植入 Agent 强制执行，满足政务系统安全合规要求。
- **开源可控**：Apache 2.0 许可证开源，代码托管于 GitHub，2026 年 5-6 月两月完成 62 次规范提交。

## 三、核心技术成果

### 3.1 自建 Agent 引擎（EcoAgentEngine）

完全自主开发的对话循环引擎，不依赖任何外部 Agent 框架。核心能力包括：

- **多模型路由与降级**：支持 DeepSeek/Qwen/GLM 等多模型，单一模型故障时自动降级到备用模型，保障服务连续性。
- **上下文压缩**：对标 Hermes trajectory_compressor，在对话超出 token 限制时自动压缩历史轮次，保护首尾关键信息。
- **安全护栏**：每轮对话经过工具权限验证、探索限制、输出验证三道防线。
- **流式输出 + 工具调用**：SSE 实时推送，支持 Agent 在对话中调用 47 个内置工具。

### 3.2 六层安全链

```
L0 全局异常脱敏 → L1 Prompt 注入检测 → L2 策略护栏
→ L3 输出验证 → L4 幻觉检测 → L5 审计追踪 → L6 国密审批
```

已通过 15 种注入攻击测试，SQL/XSS 全拦截，路径遍历防护。L6 层集成 SM2/SM3/SM4 国密算法，满足《政务信息系统密码应用与安全性评估要求》。所有 L3 级别输出均标注"须经人工审核确认后方可作为执法依据"。

### 3.4 法规知识库向量化检索（RAG）

- **语义搜索**：能理解"废气排放 = 大气污染物"，"黑烟浓度 = 林格曼黑度"等专业术语的等价关系。
- **技术栈**：TF-IDF + SVD 向量化 + BM25 关键词双路混合检索，RRF（Reciprocal Rank Fusion）融合排序。
- **零外部依赖**：SQLite + numpy 实现，法规数据不出内网。
- **已对接数据源**：湖南省生态环境厅官网 6 大板块的 4000+ 篇政策文件，涵盖规范性文件、政策解读、通知公告、环保动态、环境要闻。

### 3.5 三层知识图谱

```
Layer 1 (法规层): 法规→法规 引用网络 → RAG 注入时自动构建
Layer 2 (会话层): 会话→法规 搜索关联 → 每次执法咨询时实时追加
Layer 3 (进化层): 跨会话聚合 → 夜间反思时自动生成高频引用/共现模式/知识缺口
```

三层全部持久化在 SQLite，零外部数据库依赖。与闭环学习引擎深度联动，每办一个案件，图谱就多一层关系。

### 3.6 四平台消息网关

支持飞书、微信（公众号）、企业微信、钉钉四大国内主流即时通讯平台。

- **扫码即连**：飞书设备码流 + 企微 OAuth + 钉钉 OAuth + 微信关注，5 分钟内完成配置。
- **统一会话管理**：跨平台统一会话 ID，同一执法人员在飞书和微信上的对话可关联到同一案件。
- **移动端适配**：自动分段长文本，移动端阅读友好。

### 3.7 持续进化引擎

- **记忆蒸馏**：自动合并重复记忆，提取多次对话中的共同模式。
- **遗忘曲线**：基于 Ebbinghaus 遗忘曲线，不常用的记忆自动降权，重要的自动强化。
- **夜间反思**：每日凌晨聚合最近 24 小时的所有会话，发现高频问题模式、用户纠正趋势、知识缺口。
- **用户画像**：被动学习用户偏好（管辖区域、常用领域、详细程度偏好），隐私可控（可查看/导出/删除）。
