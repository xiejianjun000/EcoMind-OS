# Taiji Agent 架构迁移指南：v2.0 → v6.5

> 版本：1.0 | 最后更新：2026-05-27
> 状态：P2 规划阶段（待实施）

---

## 一、概述

本文档记录 EcoMind OS 从 Taiji Agent 2.0 向 v6.5 架构的迁移策略。

### 版本演进

| 版本   | 时间       | 核心特性                                           |
|--------|------------|---------------------------------------------------|
| v2.0   | 2024 Q3    | 单 Agent 指令执行、基础 Tool Calling               |
| v3.0   | 2024 Q4    | 多 Agent 协作、部门 Agent 映射                      |
| v4.0   | 2025 Q1    | ECC 技能系统、Instincts 引擎                       |
| v5.0   | 2025 Q3    | GOVMCP 国密安全、审批流引擎                         |
| v6.0   | 2026 Q1    | GraphRAG 知识图谱、联邦蒸馏推理                      |
| **v6.5** | **2026 Q2** | **SafetyChain 六层安全、NATS 消息总线、技能市场**    |

## 五、接口兼容策略

### 5.1 API 版本化

```
/api/v2/agents/chat     → 保留 v2.0 接口（兼容期 6 个月）
/api/v6/agents/chat     → 新增 v6.5 接口（SSE + SafetyChain）
/api/agents/chat        → 默认指向 v6.5
```

### 5.2 渐进式迁移

1. **影子流量阶段**（Month 1-2）
   - v2.0 和 v6.5 同时运行
   - 请求双发，对比输出差异
   - 收集兼容性数据

2. **灰度切换阶段**（Month 3-4）
   - 按市州分批切换
   - 先长沙/株洲 → 全省推广
   - 保留 v2.0 回退能力

3. **全量迁移阶段**（Month 5-6）
   - 全量切换至 v6.5
   - v2.0 降级为只读模式
   - 6 个月后下线 v2.0

### 5.3 数据迁移

| 数据类型     | 源位置              | 目标位置              | 迁移方式         |
|-------------|---------------------|----------------------|-----------------|
| Agent 配置   | v2.0 JSON           | SQLite memory        | ETL 脚本         |
| 对话历史     | v2.0 文件系统        | chatStore localStorage | 前端迁移         |
| 审批记录     | v2.0 无              | JetStream 持久化      | 新数据创建       |
| 法规知识库   | v2.0 静态 JSON       | GraphRAG 图谱         | Neo4j 导入       |

## 六、回滚方案

如果在迁移过程中出现严重问题，按以下步骤回滚：

### 快速回滚（< 30 分钟）
```bash
# 1. 切换 DNS/负载均衡回 v2.0
kubectl set image deployment/ecomind-agent agent=v2.0-latest

# 2. 禁用 SafetyChain（allow-all 模式）
curl -X POST /api/safety-chain/config -d '{"mode": "bypass"}'

# 3. 恢复 v2.0 直接 LLM 调用
export MODEL_ROUTING_STRATEGY=direct
```

### 数据回滚
```bash
# 恢复 v2.0 对话数据
cp /backup/v2-conversations/* /data/conversations/

# 回滚 JetStream 事件
nats stream purge APPROVAL_EVENTS --keep 0
```

## 七、风险评估

| 风险                      | 影响 | 概率 | 缓解措施                         |
|---------------------------|------|------|----------------------------------|
| SafetyChain 误拦截正常请求  | 高   | 中   | bypass 模式 + 阈值可配置          |
| Ollama 推理延迟过高        | 中   | 高   | 云端 fallback + 请求队列优先级    |
| NATS 消息丢失              | 高   | 低   | JetStream 持久化 + ACK 确认       |
| 国密证书兼容性问题          | 中   | 中   | 多算法回退链 SM2→RSA→ECC         |
| 模型蒸馏质量不达标          | 中   | 高   | 教师模型在线兜底 + 质量阈值过滤   |
