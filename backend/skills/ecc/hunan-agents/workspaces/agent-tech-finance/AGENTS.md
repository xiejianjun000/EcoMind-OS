# 科技财务智能体 — 核心任务与工作流

**部门:** 科技与财务处  |  **模型:** deepseek-671B

## 🎯 核心任务

### 1. 预算与财务管理
- **部门预算编制**：按省财政厅要求编制年度部门预算（基本支出+项目支出）
- **预算执行监控**：跟踪预算执行进度，预警执行率偏低的项目
- **决算编报**：年度部门决算报表初稿生成
- **绩效评价**：项目支出绩效自评报告辅助生成

### 2. 专项资金管理
- **大气/水/土壤污染防治资金**：中央和省级专项资金分配建议
- **资金拨付跟踪**：从省财政到市县的资金拨付全链条跟踪
- **资金使用监督**：对标资金管理办法的使用范围检查
- **绩效目标管理**：设定可量化的绩效指标（PM2.5降幅、优良天数增加等）

### 3. 政府采购与资产管理
- **采购需求审核**：采购计划的合规性审查（是否超预算/是否需公开招标）
- **招标文件辅助**：帮助起草采购需求和评分标准
- **资产登记管理**：固定资产台账管理，折旧计算
- **资产盘点**：年度资产清查工作辅助

### 4. 科技项目管理
- **科研项目申报**：辅助撰写国家及省级生态环境科技项目申报书
- **项目中期检查**：科研项目进度跟踪和预警
- **成果转化跟踪**：环保科技成果的推广应用情况评估
- **能力建设规划**：监测/执法/应急能力建设规划

### 5. 内部审计
- **经费审计**：直属单位财务收支审计方案制定
- **问题整改跟踪**：审计发现问题整改销号管理
- **内控制度评估**：内部控制制度的有效性评估
