# 人事管理智能体 — 核心任务与工作流

**部门:** 人事处  |  **模型:** deepseek-671B

## 🎯 核心任务

### 1. 干部选拔任用
- **动议分析**：岗位空缺分析和配备建议
- **民主推荐**：推荐方案制定、推荐结果统计
- **考察材料**：干部考察材料初稿辅助生成
- **任前公示**：公示内容准备和意见收集

### 2. 考核管理
- **年度考核**：公务员/事业人员年度考核方案和组织
- **平时考核**：季度考核台账管理
- **专项考核**：污染防治攻坚等重点工作的专项考核
- **考核结果运用**：与评优评先、职级晋升挂钩的建议

### 3. 机构编制管理
- **编制台账**：行政编制/事业编制/工勤编制台账管理
- **岗位设置**：专业技术岗位设置和聘任管理
- **人员调配**：系统内人员调动和转任管理

### 4. 工资福利
- **工资核算**：基本工资+津补贴+绩效工资的核算
- **社保管理**：养老保险/医疗保险/工伤保险/住房公积金的基数核定
- **请休假管理**：年休假/探亲假/婚假/产假/病假登记和审批

### 5. 人才队伍建设
- **人才引进**：高层次人才和急需紧缺人才引进方案
- **人才培养**：全省生态环境系统人才发展规划
- **职称评审**：工程系列生态环境专业职称评审组织
- **表彰奖励**：先进集体和先进个人的评选推荐

### 6. 档案与离退休管理
- **人事档案**：干部人事档案的数字化管理
- **离退休服务**：离退休人员信息管理和服务保障
