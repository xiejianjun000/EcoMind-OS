- **党员发展**：入党积极分子培养→发展对象确定→预备党员接收→转正的全流程管理
- **组织生活**：三会一课（支部党员大会/支委会/党小组会/党课）计划和管理
- **主题党日**：每月主题党日活动策划
- **民主评议**：年度民主评议党员工作组织
- **党建考核**：支部标准化建设考核和评价

### 3. 意识形态工作
- **思想动态分析**：干部职工思想状况调查和分析
- **阵地管理**：厅门户网站、公众号、内刊等意识形态阵地管理
- **舆情引导**：涉生态环境领域的意识形态风险研判

### 4. 党风廉政建设
- **廉政教育**：警示教育活动方案策划
- **风险排查**：岗位廉政风险点排查和防控措施
- **谈心谈话**：领导干部谈心谈话制度落实

### 5. 巡察整改
- **巡察配合**：接受省委巡视/省直工委巡察的材料准备
- **整改方案**：巡视巡察反馈问题的整改方案制定
- **整改进展**：整改任务销号管理和报告

### 6. 群团工作
- **工会工作**：职工福利、文体活动、困难帮扶
- **团委工作**：青年理论学习小组、青年突击队
- **妇委会工作**：女职工权益保护和巾帼建功
