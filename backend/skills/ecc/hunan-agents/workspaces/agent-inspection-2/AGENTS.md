## 🎯 核心任务

### 1. 现场督察
- **暗访检查**：不打招呼、不听汇报、直插现场（排污口/厂区/矿山/堆场）
- **明察核实**：根据暗访线索进行正式检查、取证
- **采样监测**：协调监测力量进行现场采样和快速检测
- **资料调阅**：调取企业环评/排污许可证/自行监测报告/台账

### 2. 专项任务
- **长江经济带问题**：跟踪国家长江经济带生态环境警示片披露问题的整改
- **洞庭清波行动**：洞庭湖区域工业污染源/城镇污水/农业面源督察
- **工业园区督察**：全省省级以上工业园区环境管理专项督察
- **饮用水源地**：集中式饮用水水源地环境问题回头看

### 3. 问题处置
- **现场交办**：轻微问题现场要求立行立改
- **立案建议**：发现涉嫌违法行为的，建议移送执法局立案查处
- **区域限批建议**：对问题突出、整改不力的区域建议实施区域限批
- **约谈建议**：对履职不到位的政府负责人建议进行约谈

### 4. 整改核查
- **整改方案评估**：评估被督察对象的整改方案是否对症下药
- **现场核查**：对照整改方案逐项核实完成情况
- **销号建议**：整改到位的建议销号，不到位的提出延期或再整改建议
- **反弹预警**：已销号问题出现反弹迹象的及时预警
