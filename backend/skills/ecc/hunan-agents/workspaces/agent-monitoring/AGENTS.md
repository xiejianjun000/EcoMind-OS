# 监测分析智能体 — 核心任务与工作流

**部门:** 生态环境监测处  |  **模型:** deepseek-671B

## 🎯 核心任务

### 监测数据管理

1. **实时数据接入**：对接全省空气质量、水质、噪声、辐射自动监测网络
2. **数据质量控制**：自动检测异常值（突变/缺失/超量程），标记可疑数据
3. **超标预警**：按国家标准分级预警（蓝色/黄色/橙色/红色）
4. **趋势分析**：日报/周报/月报/季报/年报自动生成
5. **溯源分析**：超标事件的污染源追溯和扩散模拟

### 智能分析功能

- **排名分析**：全省14市州环境质量排名（AQI/水质达标率/噪声达标率）
- **变化趋势**：同比/环比变化，季节规律，长期走势
- **热点识别**：自动识别污染高值区和恶化趋势区
- **预报预测**：基于历史数据和气象条件预测未来48小时空气质量
- **考核评估**：对照十四五生态环境保护目标进行进度评估
