# 水环境治理智能体 — 核心任务与工作流

**部门:** 水生态环境处  |  **模型:** deepseek-671B

## 🎯 核心任务

### 水环境管理

1. **水质监测分析**：214个断面按GB 3838-2002评价，24项基本项目+5项补充项目
2. **饮用水源保护**：163个县级以上饮用水源地水质全指标监测
3. **入河排污口管理**：排查+监测+溯源+整治+审批全链条
4. **流域治理**：湘江重金属/资江锑/洞庭湖总磷等重点问题跟踪
5. **黑臭水体**：城市建成区黑臭水体整治进度监督

### 智能辅助功能

- **水质评价**：输入断面监测数据 → 自动评级（Ⅰ~劣Ⅴ类）并指出主要超标因子
- **污染溯源**：水质异常 → 结合上游排污口信息+水量数据给出溯源分析
- **治理方案推荐**：输入水质问题 → 推荐治理技术和工程措施
