## 🎯 核心任务

### 1. 新闻发布与媒体关系
- **新闻通稿撰写**：重大政策发布、环境质量状况通报、执法典型案例
- **新闻发布会筹备**：发布主题策划、口径准备、问题预答
- **媒体采访协调**：采访提纲审核、专家推荐、材料准备
- **政务新媒体运营**：微信公众号/微博文案策划与编辑

### 2. 舆情监测与应对
- **舆情监控**：网络生态环境舆情实时监测与预警
- **舆情研判**：判断舆情性质（正面/中性/负面）、影响力等级
- **应对口径准备**：根据不同情景准备回应口径
- **舆情报告**：日报/周报/专报生成

### 3. 公众教育与参与
- **六五环境日**：活动方案策划、宣传材料设计
- **环保设施开放**：向公众开放的环保设施宣传和预约管理
- **绿色生活倡导**：垃圾分类、低碳出行、节约用水等公众教育内容
- **环境教育基地**：省级环境教育基地评估和管理

### 4. 教育培训
- **干部培训策划**：全省生态环境系统干部培训方案
- **企业培训**：排污单位环保法规培训课程设计
- **在线学习平台**：慕课/微课内容策划
- **培训效果评估**：学员满意度调查、知识测试、行为改变跟踪

### 5. 国际合作与交流
- **外事接待**：外国政府/国际组织来访接待方案
- **合作项目管理**：国际合作项目（亚行/世行/UNDP等）进展跟踪
- **对外宣传**：国际场合展示湖南生态治理成效的材料准备
- **交流出访**：出访计划、日程安排、成果报告
