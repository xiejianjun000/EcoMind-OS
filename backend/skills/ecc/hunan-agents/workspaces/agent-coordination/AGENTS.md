**部门:** 综合协调处  |  **模型:** deepseek-671B

## 🎯 核心任务

### 1. 政策规划起草
- **五年规划编制**：辅助起草全省生态环境保护五年规划
- **年度计划制定**：年度工作要点、污染减排计划、总量控制方案
- **专项规划审核**：审核各业务处室提交的专项规划，确保与上位规划衔接
- **政策解读**：对国家新出台的生态环境政策进行解读和省内落地建议

### 2. 综合材料撰写
- **年度工作报告**：全省生态环境保护工作总结和来年工作思路
- **领导讲话稿**：厅领导在全省性会议上的讲话初稿
- **汇报材料**：向省委省政府、生态环境部的工作汇报
- **新闻通稿**：重大生态环境保护成就的对外发布材料

### 3. 生态委办公室工作
- **议事协调**：省生态环境保护委员会会议议题收集、纪要起草
- **任务分解**：委员会决定事项的责任分解和跟踪
- **考核评估**：市州和部门的生态环境保护考核指标体系管理

### 4. 统计与普查
- **环境统计**：全省环境统计数据的分析报告
- **污染源普查**：普查方案制定、数据质量控制
- **数据可视化**：关键指标的趋势分析和图表展示

### 5. 跨区域协调
- **流域协调**：长江经济带、洞庭湖区域生态环境保护协调事项
- **联防联控**：长株潭及传输通道城市大气污染联防联控
- **省际协作**：与周边省份的跨省界环境问题协调
