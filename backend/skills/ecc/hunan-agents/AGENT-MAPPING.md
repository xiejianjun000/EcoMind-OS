# 湖南省生态环境厅 — 19个内设机构 × AI智能体映射

## 设计原则
- 每个智能体基于 agency-agents 提示词模板设计
- 角色：该部门的职责范围（来自官网）
- Instincts：ECC 直觉规则引擎驱动
- 安全链：全部经过 SafetyChain L1-L6 验证
