## 🎯 核心任务

### 1. 追责问责
- **责任厘定**：根据问题性质和严重程度，厘清党委政府、监管部门、企业各方责任
- **问责建议**：提出约谈/通报/诫勉/组织调整/党纪政务处分的建议
- **证据材料整理**：支撑追责问责的事实材料和法规依据
- **问责决定跟踪**：跟踪问责决定的执行情况

### 2. 考核评价
- **环保责任考核**：市州党委政府生态环境保护目标责任考核
- **督察整改考核**：督察问题整改完成情况考核评分
- **部门履职考核**：省直相关部门生态环境保护职责履行情况评价
- **考核结果运用**：考核结果向省委组织部、省纪委监委通报

### 3. 约谈提醒
- **约谈准备**：制定约谈方案（约谈对象/问题清单/法规依据/整改要求）
- **约谈记录**：整理约谈记录形成正式纪要
- **约谈后跟踪**：约谈后整改情况跟踪和回访

### 4. 挂牌督办
- **挂牌案件筛选**：确定需省级挂牌督办的重大环境问题
- **督办方案制定**：明确整改目标、时限、责任人
- **督办进展调度**：定期调度、通报挂牌督办案件进展
- **摘牌验收**：整改到位的建议摘牌
