# 神探 Skill (Sherlock) — 深度取证智能体

> ECO-Audit V3.0 五智能体架构 · Agent 2

---

## 1. Skill 名称和描述

**名称**: `eco-audit/sherlock-skill`
**代号**: 神探 (Sherlock)
**描述**: ECO-Audit 系统的"深度取证引擎"。在哨兵快速扫描的基础上，调用协议适配器插件，通过串口/以太网/OPC-UA 等接口读取分析仪内部诊断数据，执行数据逻辑校验规则（R051-R100）和物理链路审计规则（R101-R130），形成完整的证据采集层。

**核心设计理念**: "深度见底" —— 穿透表面数据，直达分析仪内部状态和物理链路真实情况。

## 2. 触发条件

| 触发场景 | 示例 |
|----------|------|
| 哨兵扫描完成 | Sentry 输出异常清单后自动触发 |
| 用户手动触发深度取证 | "启动深度取证"、"神探上场" |
| 标准/完整模式审计 | 非快速模式下自动调度 |
| 哨兵发现高危异常 | 高危异常立即触发针对性深度取证 |

## 3. 核心能力清单

### 3.1 协议适配器调用
- **HJ 212 协议适配器**: 解析 HJ 212-2017/2025 数据包，提取原始监测数据
- **Modbus TCP/RTU 适配器**: 通过 Modbus 协议读取分析仪内部寄存器
- **OPC-UA 适配器**: 通过 OPC-UA 接口获取实时诊断参数（完整模式）
- **串口通信适配器**: RS-232/485 直连分析仪读取内部日志
- **以太网直连适配器**: 通过网络接口获取分析仪 Web 管理页面数据

### 3.2 数据逻辑深度校验
- 多因子时序关联分析：治理设施运行参数 ↔ 排放浓度
- 生产工况关联：DCS 负荷数据 ↔ 排放数据时序对齐
- 统计特征分析：频谱分析、自相关性、周期性检测（傅里叶/小波）
- 质量守恒校验：碳平衡、硫平衡、氮平衡方程构建
- 物料衡算反推：基于排污许可证反推理论排放浓度范围

### 3.3 物理链路深度审计
- 全程伴热温度链：探头 → 伴热管线 → 冷凝器 温度连续性
- 气密性/压力链：采样泵负载、管路压力、漏气检测
- 等速跟踪审计：等速跟踪误差持续监测（±8% 阈值）
- 核心传感器诊断：FID 火焰状态、光学传感器光强、检测器噪声
- 预处理系统适用性评估：当前工况下的预处理方式合规性

### 3.4 证据固化
- 原始数据包捕获：HJ 212 原始报文完整保存
- 时序快照：关键参数的时间序列快照（带时间戳）
- 协议交互日志：所有适配器通信日志完整记录
- 证据链 ID 标记：每条证据生成唯一 SHA256 指纹

## 9. 与其他智能体的协作关系

```
Sentry (哨兵) ──异常清单──→ Sherlock (神探) ──证据包──→ Expert (专家)
                                   │
                                   └── 协议规范查询 ──→ Librarian (智库)
```

- **上游**: 接收哨兵异常清单，确定深度取证方向
- **下游**: 输出带 SHA256 指纹的证据包，供专家研判
- **并行**: 通过 Librarian 获取协议规范、设备手册、已知作弊特征库

---

## 10. 注意事项

1. **协议安全**: 所有协议适配器操作仅读取数据，不发送任何修改指令
2. **品牌兼容**: 标准模式支持 ≥8 个主流品牌，完整模式支持 ≥15 个品牌
3. **超时控制**: 单个分析仪连接超时 120 秒，自动标记 "连接失败" 并跳过
4. **证据完整性**: 所有原始数据包必须附带 SHA256 指纹，确保证据链可追溯
5. **异常降级**: 当协议适配器无法连接时，标记 "协议适配失败"，不影响其他规则执行
