# 哨兵 Skill (Sentry) — 快速扫描智能体

> ECO-Audit V3.0 五智能体架构 · Agent 1

---

## 1. Skill 名称和描述

**名称**: `eco-audit/sentry-skill`
**代号**: 哨兵 (Sentry)
**描述**: ECO-Audit 系统的"第一道防线"。在审计流程启动后 5 分钟内完成对目标工控机/分析仪的初步快速扫描，覆盖文件、进程、配置参数、时间同步、基础数据连续性等维度，输出异常清单供后续神探深度取证使用。

**核心设计理念**: "先广后深" —— 用最小代价获取最大覆盖面的初步筛查结果，为神探 Skill 指明深度调查方向。

## 3. 核心能力清单

### 3.1 文件系统快速扫描
- YARA 规则库扫描：隐藏菜单入口、后门程序、默认工程密码
- 进程白名单比对：提取运行进程 vs 验收基线，标记异常
- 文件完整性检查：关键配置文件哈希校验
- 日志完整性初筛：检测长时段空白、异常删除痕迹

### 3.2 参数一致性快检
- 四方参数比对：分析仪 EEPROM ↔ 数采仪配置 ↔ 工控机软件 ↔ 验收报告
- 量程匹配性审计：量程设置 vs 排污许可限值
- 时间同步检查：数采仪/分析仪/工控机时钟偏差（阈值 ±1 分钟）
- 点位编号一致性：现场编号 ↔ 分析仪配置 ↔ 数采仪上报 ↔ 排污许可证

### 3.3 基础数据逻辑快检
- 长期恒值检测：变异系数(CV) 低于量程 1% 的时段
- 逻辑矛盾检测：氨氮 > 总氮、COD < BOD 等化学原理违反
- 数据连续性校验：排放量数据长期为零或空值的断点
- 过滤器堵塞初筛：压差超限告警
- 校准周期初筛：长期未校准情况

### 3.4 资质与信用快检
- 第三方检测机构资质查询：CMA 资质有效性
- 设备认证与铭牌一致性：CCEP 认证证书核验

## 4. 工作流程

```
┌─────────────────────────────────────────────────────┐
│                    哨兵工作流程                        │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Step 1: 环境初始化                                   │
│  ├─ 接收 Guardian 只读挂载路径                         │
│  ├─ 加载规则引擎（快速模式规则子集）                      │
│  └─ 初始化 Librarian 检索连接                          │
│                                                     │
│  Step 2: 并发扫描（并行执行）                            │
│  ├─ [线程A] YARA 规则扫描 + 进程白名单比对                │
│  ├─ [线程B] 四方参数一致性比对                           │
│  ├─ [线程C] 基础数据逻辑快检                            │
│  └─ [线程D] 时间同步 + 点位编号校验                      │
│                                                     │
│  Step 3: 结果汇总与分级                                 │
│  ├─ 异常条目分级：高危/中危/低危                          │
│  ├─ 生成结构化异常清单（JSON）                           │
│  └─ 标注建议深入调查的规则ID                             │
│                                                     │
│  Step 4: 结果传递                                      │
│  ├─ 输出至 OpenClaw 结果总线                           │
│  ├─ 触发 Sherlock（神探）深度取证                       │
│  └─ 记录扫描日志                                       │
│                                                     │
│  ⏱ 目标耗时: ≤5 分钟                                  │
└─────────────────────────────────────────────────────┘
```

## 9. 与其他智能体的协作关系

```
Guardian (门神) ──只读挂载完成──→ Sentry (哨兵) ──异常清单──→ Sherlock (神探)
                                      │
                                      └── 实时查询 ──→ Librarian (智库)
```

- **上游**: Guardian 完成只读挂载和基线校验后，哨兵开始扫描
- **下游**: 扫描完成后输出结构化异常清单，触发神探深度取证
- **并行**: 通过 Librarian 获取法规条款、历史案例和特征库信息

---

## 10. 注意事项

1. **只读原则**: 所有扫描操作必须在只读挂载的磁盘上执行，禁止任何写入
2. **超时控制**: 单线程扫描超过 3 分钟自动降级为 "未完成" 标记
3. **内存约束**: 快速模式下总内存占用不超过 512MB
4. **误报处理**: 所有初筛结果标记为 "待核实"，最终结论由专家判定
