# 专家 Skill (Expert) — 智能研判智能体

> ECO-Audit V3.0 五智能体架构 · Agent 3

---

## 1. Skill 名称和描述

**名称**: `eco-audit/expert-skill`
**代号**: 专家 (Expert)
**描述**: ECO-Audit 系统的"大脑"。汇总哨兵和神探的初步结果，执行运维质控规则（R131-R160）、第三方检测规则（R161-R180）和特定行业规则（R181-R200），调用本地 LLM（Qwen2.5-3B/7B 量化版）进行法律条款映射、置信度评估和证据链组装。同时运行自进化学习引擎，从历史审计案例中提取新模式。

**核心设计理念**: "智能研判" —— 将分散的异常条目组装为完整的证据链，提供可采信的法律判定建议。

## 3. 核心能力清单

### 3.1 规则引擎深度执行
- 运维与质控规范审计（R131-R160）：校准周期、数据标记、修约合规、运维到场真实性
- 第三方检测报告审计（R161-R180）：方法适用性、采样流程、实验室质控、资质信用
- 特定行业专项规则（R181-R200）：垃圾焚烧、湿法脱硫、VOCs、超低排放、水泥、钢铁等

### 3.2 LLM 智能研判
- **法律条款映射**: 将异常条目自动映射到相关法律法规条款
- **置信度评估**: 基于复合计算模型（模式基础分 × 协议覆盖系数 × 数据完整系数）评估每条异常的可信度
- **证据链组装**: 将分散的异常条目关联为完整的违法行为证据链
- **自然语言报告**: 生成可读的审计结论和执行摘要

### 3.3 自进化学习引擎
- **模式提取**: 从已确认的审计结果中提取新的作弊模式
- **规则生成**: 自动生成新的检测规则建议
- **特征库更新**: 更新 YARA 规则库和作弊特征库
- **经验积累**: 记录误报/漏报案例，优化未来判定阈值

### 3.4 报告生成
- 执行摘要（PDF）：面向执法人员的简明结论
- 技术报告（HTML）：面向技术人员的详细分析
- 法证报告（ZIP）：完整证据包，含 SHA256 校验，面向法庭使用

## 4. 工作流程

```
┌─────────────────────────────────────────────────────────┐
│                    专家工作流程                            │
├─────────────────────────────────────────────────────────┤
│                                                         │
│  Step 1: 接收前置结果                                     │
│  ├─ 解析 Sentry 异常清单（如有）                           │
│  ├─ 解析 Sherlock 证据包（如有）                           │
│  └─ 去重合并异常条目                                      │
│                                                         │
│  Step 2: 运维与质控规则执行（R131-R160）                    │
│  ├─ 校准/校验周期与内容合规审计                            │
│  ├─ 数据标记与设备状态一致性校验                            │
│  ├─ 运维人员到场真实性审计                                │
│  └─ 运维台账完整性和一致性校验                             │
│                                                         │
│  Step 3: 第三方检测规则执行（R161-R180）                    │
│  ├─ 手工监测报告方法适用性审计                             │
│  ├─ 实验室分析质控合规性审计                              │
│  └─ 第三方检测机构资质与信用风险预警                        │
│                                                         │
│  Step 4: 特定行业规则执行（R181-R200）                      │
│  ├─ 垃圾焚烧工况标记合规性                                 │
│  ├─ VOCs治理设施旁路异常检测                               │
│  └─ 其他行业专项规则                                     │
│                                                         │
│  Step 5: LLM 智能研判                                     │
│  ├─ [LLM] 法律条款映射                                    │
│  │   └─ 输入：异常条目 + 法规知识库                        │
│  │   └─ 输出：对应法律条款 + 处罚依据                      │
│  ├─ [LLM] 置信度评估                                      │
│  │   └─ 输入：证据强度 + 数据完整性                         │
│  │   └─ 输出：置信度评分（0-100%）                         │
│  └─ [LLM] 证据链组装                                     │
│      └─ 输入：所有异常条目及其关联关系                      │
│      └─ 输出：违法行为证据链图谱                            │
│                                                         │
│  Step 6: 自进化学习（异步）                                 │
│  ├─ 提取新模式特征                                       │
│  ├─ 生成规则优化建议                                      │
│  └─ 更新特征库（需人工审核后生效）                          │
│                                                         │
│  Step 7: 报告生成与输出                                    │
│  ├─ 生成执行摘要（PDF）                                   │
│  ├─ 生成技术报告（HTML）                                  │
│  └─ 生成法证报告（ZIP，含 SHA256 校验）                    │
│                                                         │
│  ⏱ 目标耗时: ≤10 分钟（标准模式）/ ≤30 分钟（完整模式）      │
└─────────────────────────────────────────────────────────┘
```

## 9. 与其他智能体的协作关系

```
Sherlock (神探) ──证据包──→ Expert (专家) ──审计结论──→ 报告生成
                                │
                                └── 法规/案例查询 ──→ Librarian (智库)
                                │
                                └── 自进化学习 ──→ 特征库更新
```

- **上游**: 接收哨兵和神探的结果，去重合并后执行深度研判
- **下游**: 输出审计结论和完整报告
- **并行**: 通过 Librarian 获取法规条款和判例支持

---

## 10. 注意事项

1. **LLM 资源管理**: 标准模式使用 3B 量化模型（内存占用 ≤2GB），完整模式使用 7B 量化模型（内存占用 ≤6GB）
2. **置信度阈值**: 置信度 ≥80% 判定为 "高可信"，50-79% 为 "中可信"，<50% 为 "低可信"
3. **自进化学习**: 自动提取的新模式需人工审核后方可加入特征库
4. **报告签名**: 法证报告必须附带 SHA256 校验值，确保证据不被篡改
5. **法律映射**: LLM 法律映射结果仅供参考，最终法律判定由执法人员确认
