# 生态环境行政处罚案卷完整评查

> 来源: xiejianjun000/eco-case-review | 评查标准: 2024年版

## 评查流程 (8步)

1. **案卷解析**: 用 document_parse 或 document_ocr 将 PDF 转为可读文本
2. **合法性评查** (一票否决): 检查 25 项重大问题——执法主体/违法主体/违法事实/法律适用/执法程序
3. **规范性评分**: 如果合法性通过，按 100分→50分 折算文书得分
4. **裁量基准计算**: 按《湖南省生态环境行政处罚裁量权基准》计算建议处罚
5. **证据链分析**: 人证/物证/书证/电子数据完整性
6. **文书完整性**: 14类文书逐项检查
7. **综合分析**: 汇总所有评查结果
8. **生成报告**: 输出 Markdown 格式评查报告

## 法律依据

- 《生态环境行政执法案卷评查细则（2024年版）》
