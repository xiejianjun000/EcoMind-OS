### Module C: 文件上传+分析链路 — ❌ 测试引擎缺陷 (0/15)

**状态**: **非系统 BUG** — 测试引擎的 `_test_file_upload_chain()` 方法使用 `bytes` 直接 POST，未构造 `multipart/form-data` 格式的 File 对象

**错误模式**:
```
{'detail': [{'type': 'missing', 'loc': ['body', 'file'], 
  'msg': 'Field required', 'input': None}]}
```

**根因**: [stress_test_engine.py](file:///Users/mac/EcoMind-OS/tests/stress_test_engine.py) 中 `upload_file()` 方法需要修复为使用 `aiohttp.FormData` 构造 multipart 请求

**建议修复**:
```python
async def upload_file(self, file_content: bytes, filename: str) -> tuple[int, dict, float, int]:
    form = aiohttp.FormData()
    form.add_field('file', file_content, filename=filename, content_type='application/octet-stream')
    async with self.session.post(f"{self.base_url}/api/upload", data=form) as resp:
        ...
```

**注意**: 此缺陷不影响对系统本身的评估。前端浏览器中的文件上传已通过三层防御修复验证。

### C1: SQL 错误信息泄露 — ✅ 已修复

**修改文件**:
- [main.py:128-142](file:///Users/mac/EcoMind-OS/backend/api/main.py#L128-L142) — 全局异常处理器
- [chat.py:181-183](file:///Users/mac/EcoMind-OS/backend/api/routers/chat.py#L181-L183) — 流式端点脱敏
- [chat.py:240-242](file:///Users/mac/EcoMind-OS/backend/api/routers/chat.py#L240-L242) — 非流式端点脱敏

**防护机制**:
```python
@application.exception_handler(Exception)
async def global_exception_handler(request, exc):
    request_id = str(uuid.uuid4())[:8]
    logger.error(f"[{request_id}] 未处理异常: {exc}\n{traceback.format_exc()}")
    return JSONResponse(status_code=500, content={
        "error": "internal_server_error",
        "message": "服务器内部错误",
        "request_id": request_id,
    })
```

**效果**: 即使数据库连接失败、SQL 语法错误、ORM 异常，客户端只能看到 `"服务器内部错误"` + `request_id`，运维人员通过日志 `request_id` 定位问题。

### H1: 文件路径信息泄露 — ✅ 已修复

**修改文件**: [upload.py:27-44](file:///Users/mac/EcoMind-OS/backend/api/routers/upload.py#L27-L44)

**虚拟路径映射层**:
```python
VIRTUAL_BASE = "/files/"

def _to_virtual(real_path: str) -> str:
    token = f"f-{uuid.uuid4().hex[:16]}"
    _path_map[token] = real_path
    return f"{VIRTUAL_BASE}{token}"

def _from_virtual(virtual_path: str) -> Optional[str]:
    token = virtual_path[len(VIRTUAL_BASE):]
    return _path_map.get(token)
```

**映射示例**:
| 场景 | 修复前 (危险) | 修复后 (安全) |
|------|--------------|---------------|
| 上传返回 | `/tmp/ecomind_uploads/uf-a1b2c3.pdf` | `/files/f-a1b2c3d4e5f6g7h8` |
| 列表返回 | `/tmp/ecomind_uploads/session_xxx/file.pdf` | `/files/f-b2c3d4e5f6g7h8i9` |
| 错误响应 | `file not found: /tmp/ecomind_uploads/xxx` | `文件路径无效或已过期` |
