## 4. 技术实现路径

### 4.1 页面优先级 (分3期实施)

```
Phase 1 (立即) ── 领导驾驶舱 + 监测一张图 + 审批中心
Phase 2 (1周)  ── 执法办案 + 安全升级 + Agent升级
Phase 3 (2周)  ── 审计日志 + 技能/记忆可视化 + 公众门户
```

### 4.2 组件复用策略

```
已有组件 → 新页面复用:
  KpiCard         → 驾驶舱/监测/执法统计卡片
  AgentTable      → Agent总览/驾驶舱Agent状态
  SecurityEvents  → 安全态势/驾驶舱告警列表
  PendingApprovals→ 审批中心/驾驶舱待审批
  AgentStats      → 驾驶舱/Agent总览
  ModelRouter     → 驾驶舱/模型管理
  HunanTerrainScene→ 监测一张图/驾驶舱
  MonitoringStation→ 监测一张图
  StationPopup    → 监测一张图

新增公共组件:
  PageHeader      → 统一页面头部(标题+面包屑+操作按钮)
  StatusBadge     → 状态标签(在线/离线/告警/审批中)
  TimelineView    → 时间线视图(执法/审批/审计)
  SearchPanel     → 高级搜索面板
  ExportButton    → 导出按钮(dropdown: CSV/PDF/Excel)
  AiAssistant     → AI助手浮动按钮(全局)
```

### 4.3 关键技术决策

| 决策点 | 方案 | 理由 |
|--------|------|------|
| 地图框架 | Cesium 1.127 + Deck.gl 9 | 已有基础，3D地形+数据图层 |
| 图表框架 | ECharts 5.6 (保留) | 政务标准，支持大屏 |
| 状态管理 | Zustand 5 (保留) | 轻量，已有WebSocket集成 |
| UI框架 | Ant Design 5.24 + ProComponents | 企业级，政务适配 |
| CSS方案 | Tailwind CSS 4 (保留) | 原子化，快速定制 |
| 大屏适配 | CSS transform: scale + media query | 4K/8K自适应 |
| 移动端 | 响应式 + PWA | 政务APP可后续Native |
| 离线能力 | Service Worker + IndexedDB | 执法现场可能无网络 |

## 6. 安全前端要求（政务合规）

```
✅ 等保三级要求:
  - 登录: 国密SM2证书 + 密码双因子
  - 超时: 30分钟无操作自动登出
  - 水印: 页面水印(用户名+时间)防截屏泄露
  - 脱敏: 身份证/手机号前端脱敏显示
  - 审计: 所有操作前端记录(埋点)
  - 三员分立: 系统管理员/安全保密员/安全审计员

✅ 国密适配:
  - 前端SM2加密传输敏感数据
  - 数字签名可视化验证
```
